# UX Copy

## Homepage hero
### Headline
**Who are you thinking of trusting?**

### Subheadline
Search the public web, verify claims, and see the original sources before you make an important decision.

### Search fields
- Full name
- City or country (optional)
- Employer or organization (optional)
- Username or profile link (optional)

### CTA
**Search the public web**

### Supporting promises
- **Transparent** — See original sources for meaningful findings.
- **Contextual** — We organize information so it is easier to evaluate.
- **Private by design** — The MVP does not save your searches.

## Candidate selection
### Heading
**Is this the person?**

### Candidate labels
- High-confidence match
- Possible match
- Probably a different person

### Actions
- This is them
- Not them
- Search again

## Report intro
### Heading
**Trust Brief**

### Disclaimer
This report summarizes publicly available information and may be incomplete or incorrect. A missing record does not prove safety, and an allegation does not prove wrongdoing. Review the original sources before drawing conclusions.

## Empty result
**We couldn't find enough reliable public information to build a useful report.**

We will never turn an empty search into a fake warning or pretend that "nothing found" means someone is safe.
