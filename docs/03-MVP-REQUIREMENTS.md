# MVP Requirements

## P0 — must have
- Name search.
- Optional context: location, employer/organization, username, profile URL.
- Server-side public-web search.
- Query expansion.
- Duplicate URL removal.
- Candidate identity clustering.
- User identity confirmation before deep analysis.
- Source categorization.
- Every displayed finding links to an original source.
- Clear uncertainty labels.
- No database persistence by default.
- Privacy + limitations page.
- Abuse/safety guardrails.

## P1 — useful immediately after MVP
- Timeline generation.
- Claim verification.
- Search-provider fallback.
- Export/share a source list without exposing the user's original query.
- Optional local browser session history only.
- Search quality feedback: relevant / wrong person / low quality.

## P2 — later
- Public registries by country.
- Organization/company graph.
- Domain/website history.
- Conversation/document analysis supplied by the user.
- Multi-language search expansion.
- Optional paid deeper search.

## Explicit UX rule
Never put payment before proof of useful search coverage. If monetization is introduced, show users what categories and candidate matches were found before asking them to pay for deeper analysis.
