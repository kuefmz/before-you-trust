# MVP Launch Checklist

## Product
- [ ] Search works on distinctive and common names.
- [ ] Candidate identities are separated correctly.
- [ ] User confirms identity before deep search.
- [ ] Every finding links to a source.
- [ ] Uncertainty labels are visible.
- [ ] Empty searches are handled honestly.

## Safety/privacy
- [ ] No searched names in analytics.
- [ ] Logs reviewed/redacted.
- [ ] Privacy page live.
- [ ] Limitations disclaimer live.
- [ ] Acceptable-use rules drafted.
- [ ] Abuse reporting contact/process defined.
- [ ] Legal review completed before meaningful public scale.

## Technical
- [ ] API secrets server-side only.
- [ ] Rate limiting enabled.
- [ ] Error states handled.
- [ ] YaCy node health, CPU/RAM/disk and crawl/index capacity monitored.
- [ ] Mobile UI tested.

## Search quality
- [ ] Controlled benchmark set completed.
- [ ] Wrong-person rate reviewed.
- [ ] Duplicate handling tested.
- [ ] YaCy unavailable/timeout behavior tested.
- [ ] No fabricated source or citation paths.

## Brand
- [ ] Logo finalized.
- [ ] Favicon/app icon exported.
- [ ] Social preview image exported.
- [ ] Brand colors and Inter typography applied consistently.
